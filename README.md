# Smart File Sorter

Smart File Sorter is a Python program that helps organize files automatically.

The program scans a folder and sorts files into categories such as:

- Images
- Documents
- Music
- Videos

This makes it easier to keep folders clean and find files quickly.

## Features

- Automatic file sorting
- Easy-to-use terminal interface
- Supports multiple file types
- Beginner-friendly Python project
